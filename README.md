# OrbitGuard AI: Real-Time Space Debris & Satellite Collision Predictor

An enterprise-grade aerospace simulation engine combining **Rust** for high-speed multi-threaded orbital calculations and **Google Gemini AI** for predictive threat mitigation and emergency protocol generation.

## 🚀 Architecture & Tech Stack
- **Backend Core:** Written in **Rust** for memory safety and extreme computational speed when parsing high-velocity space objects.
- **AI Integration:** Powered by **Google Gemini SDK (`google-genai`)** to generate real-time ISRO/NASA-style collision avoidance maneuver reports.
